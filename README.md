# T-REX Capital Market

A multi-tenant ERC-3643 (T-REX) Capital Market for issuing, managing, and investing in compliant security tokens.

## Features

- Organization (KYB) onboarding
- ERC-3643 token deployment
- ONCHAINID integration
- Compliance rule management
- Investor KYC & onboarding
- Token subscription & minting
- Portfolio management
- Admin dashboard

## Tech Stack

**Frontend**
- React
- JavaScript
- Tailwind CSS
- Wagmi / Viem

**Backend**
- Node.js
- Express
- MySQL


**Blockchain**
- Solidity
- Hardhat
- ERC-3643 (T-REX)
- ONCHAINID
- Ethers.js
