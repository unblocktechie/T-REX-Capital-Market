# Logo navigation and asset contract UX update

## Changes

- The T-REX logo in the main issuer/investor sidebar is now an accessible dashboard link.
- The logo shows pointer/hover/focus behavior and closes the mobile navigation drawer after navigation.
- The issuer token details page now displays the asset contract address in the main asset summary instead of requiring users to open Technical details.
- The contract address is shortened for readability, while copy copies the full address.
- The Copy action visibly changes to `Copied` after success.
- The existing block-explorer action remains available beside the address.
- Technical details still explain the network without duplicating the full contract-address block.
- Responsive rules stack the contract explanation/address cleanly on tablet and mobile.

No token, wallet, API, transaction, price, or permission logic was changed.
